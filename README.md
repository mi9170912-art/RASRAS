# RASRAS PLASTIC ERP

نظام إدارة داخلي لشركة RASRAS PLASTIC — بيدير دورة أوامر البيع والشراء والأوامر الخارجية من الإنشاء لحد التسليم والتحصيل، بكل الاعتمادات والتقارير والطباعة.

النظام عبارة عن **ملف HTML واحد فقط** يشتغل من غير سيرفر أو تنصيب — تفتحه في أي متصفح وخلاص. البيانات بتتحفظ في متصفحك (localStorage) وميتشاركتش مع حد تاني تلقائيًا.

## إزاي تشغله

1. حمّل ملف `RASRAS_ERP.html`
2. افتحه في أي متصفح (كروم / سفاري / إيدج)
3. سجّل دخول بأحد الحسابات التجريبية تحت (كلمة السر لكل الحسابات: `1234`)

> ⚠️ البيانات بتتحفظ محليًا في المتصفح بتاعك بس. لو فتحت الملف من جهاز تاني أو متصفح تاني، هتلاقي البيانات فاضية من جديد.

## الأدوار المتاحة

| الحساب | الدور | بيعمل إيه |
|---|---|---|
| `admin` | المدير العام | يشوف ويعتمد كل حاجة، وهو الوحيد اللي يعمل أوامر خارجية، وهو والحسابات بس اللي يقدروا يلغوا أي أمر |
| `sales` | المبيعات | ينشئ أوامر بيع، يشوف تقرير مبيعاته هو بس |
| `accounts` | الحسابات | يعتمد الأوامر ماليًا، يسوّي حساب مقاول النقل، ينشئ أوامر شراء |
| `logistics` | قسم النقل | يحدد تكلفة النقل لأي أمر (بيع أو خارجي)، يشوف تقرير النقلات |
| `warehouse` | المخازن | يصرف ويستلم البضاعة (كميات فقط، من غير أسعار)، يشوف تقرير حركة المخزن |
| `driver` | السائق | يستلم أمر التوصيل ويأكد التسليم، يشوف توصيلاته هو بس |

## دورة أمر البيع

المبيعات ← اعتماد المدير ← مراجعة النقل ← اعتماد الحسابات ← إذن المخزن ← مع السائق ← تم التسليم ← (فاتورة ضريبية لو مطلوبة) ← مكتمل

## دورة أمر الشراء

الحسابات/المدير ← اعتماد المدير ← استلام المخزن ← تسوية الحسابات ← مكتمل

## الأمر الخارجي (مورد ← عميل مباشرة)

للمدير العام بس. بضاعة بتنتقل من المورد للعميل من غير ما تعدي على المخازن. بيتحدد فيها هامش الربح (سري، يظهر للمدير والحسابات بس)، ومدة الأجل لو الدفع آجل، وتكلفة النقل بيحددها قسم النقل بعد كده.

## المميزات الرئيسية

- طباعة احترافية: فواتير، أذون صرف واستلام (مسلسلة)، تقارير ضريبية، تسوية حساب النقل
- تسوية حساب مقاول النقل بدعم الدفع الجزئي والرصيد المرحّل
- تقارير مخصصة لكل دور — كل واحد يشوف اللي يخصه بس، ما عدا المدير والحسابات يشوفوا كل حاجة
- إلغاء الأوامر (للمدير والحسابات بس) مع تسجيل السبب

## ملاحظة تقنية

الملف مبني بـ HTML/CSS/JavaScript خام من غير أي مكتبات أو framework، عشان يفضل خفيف ويشتغل فورًا من غير build أو تنصيب.
